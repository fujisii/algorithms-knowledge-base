# Fibonacci DP / フィボナッチ数列（動的計画法）

**難易度**: Easy

## 概要

フィボナッチ数列（F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)）の n 番目の値を動的計画法（DP）で求めるアルゴリズム。再帰的な定義を持つが、計算済みの値を配列に保存することで再計算を防ぐ。

## アルゴリズムの直感

単純な再帰では F(n) の計算に指数時間かかる（F(5) を求めるために F(3) を複数回計算するなど、部分問題が重複する）。DP では F(0) から順に計算し、結果を配列に保存する（ボトムアップ方式）。各値は一度しか計算しないため O(n) で完了する。

Bellman (1957) が提唱した動的計画法の基本原理「重複する部分問題を分割して解き、メモ化で再計算を防ぐ」を最もシンプルに体現した例。

## 自分の解釈

再帰版との比較が理解の鍵。再帰は「トップダウン（大問題から小問題へ）」、DP は「ボトムアップ（小問題から大問題へ）」。フィボナッチ DP では配列全体を使わず変数2つで空間を O(1) にも最適化できる。本実装はDP テーブルを明示的に見せることを優先している。

## 計算量

- 時間: O(n)
- 空間: O(n)（DP テーブルの分）

## Example

```
入力: n = 6

dp の構築:
  dp[0] = 0
  dp[1] = 1
  dp[2] = dp[1] + dp[0] = 1
  dp[3] = dp[2] + dp[1] = 2
  dp[4] = dp[3] + dp[2] = 3
  dp[5] = dp[4] + dp[3] = 5
  dp[6] = dp[5] + dp[4] = 8

出力: 8
```

## 実装メモ

- n=0, n=1 の基底ケースを先にガードしないと dp 配列のインデックスが不正になる可能性がある
- 空間最適化が必要な場合は `prev, curr` の2変数に置き換えられる（本実装は可読性優先でテーブルを保持）
- TypeScript: `number` 型（IEEE 754 倍精度）は `Number.MAX_SAFE_INTEGER`（2^53-1）を超えると精度が失われる。n >= 79 では結果が不正確になる
- Go: `int` 型（64 ビット環境）は n >= 93 で符号付きオーバーフローが発生する
