# Bubble Sort / バブルソート

**難易度**: Easy

## 概要

隣り合う要素を繰り返し比較・交換することで、大きな値を末尾へ「浮き上がらせる」ソートアルゴリズム。実用的なパフォーマンスは低いが、安定ソートであり、アルゴリズムの基本構造を学ぶうえで教科書的な位置づけにある。

## アルゴリズムの直感

1回のパスで、最大値が末尾に「泡のように浮かび上がる」。これを n-1 回繰り返すと全体がソートされる。各パスでは末尾の i 個が確定済みなので、比較範囲を n-1-i まで縮める最適化が自然に成立する。

Sedgewick & Wayne (Algorithms) では「selection sort の変形で、各パスが部分的な選択を行う」と説明している。

## 自分の解釈

二重ループの内側が「隣接交換」という最小単位の操作しか行わない点が特徴。最悪ケースでは O(n²) 回の交換が発生するため、実務では選択されないが、「安定性の確保が難しいクイックソートと対比する学習材料」として有用。

## 計算量

- 時間: O(n²)（最良・平均・最悪いずれも）
- 空間: O(1)（出力配列のコピーを除く）

## Example

```
入力: [5, 3, 1, 4, 2]

パス 1 (i=0): 比較範囲 [0..3]
  j=0: 5>3 → swap → [3, 5, 1, 4, 2]
  j=1: 5>1 → swap → [3, 1, 5, 4, 2]
  j=2: 5>4 → swap → [3, 1, 4, 5, 2]
  j=3: 5>2 → swap → [3, 1, 4, 2, 5]  ← 5 が確定

パス 2 (i=1): 比較範囲 [0..2]
  j=0: 3>1 → swap → [1, 3, 4, 2, 5]
  j=1: 3<4 → no swap
  j=2: 4>2 → swap → [1, 3, 2, 4, 5]  ← 4 が確定

パス 3 (i=2): 比較範囲 [0..1]
  j=0: 3>2 → swap → [1, 2, 3, 4, 5]  ← 3 が確定

パス 4 (i=3): 比較範囲 [0..0]
  j=0: 1<2 → no swap                  ← 2 が確定

出力: [1, 2, 3, 4, 5]
```

## 実装メモ

- 元配列を破壊しないようコピーを取ってから操作する
- 内側ループの上限を `n-1-i` にすることで確定済みの末尾を再比較しない
- 早期終了の最適化（パスで交換が発生しなければ終了）は本実装では省略している（可読性優先）
